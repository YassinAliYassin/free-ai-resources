# Contributing

Thanks for helping keep **Free AI Resources** current and useful! This is a small docs
repo — contributions are simple.

## How to contribute

1. **Add or update a resource** in [`free-ai-resources.md`](./free-ai-resources.md)
   (the authoritative, sectioned list).
2. **Keep entries free-tier and verified** — include a working link and, where relevant,
   the free-tier limit.
3. **Bump the "last updated" note** when you add or change a provider.
4. Open a PR against `main` with a short description of what you changed and why.

## Guidelines

- Only legitimately **free** options (free tier or open-source/self-hostable).
- One clear section per entry; prefer the existing category structure.
- Don't add paid-only tools, obfuscated links, or affiliate-heavy content.

## PR checklist

- [ ] Entry added in the correct section of `free-ai-resources.md`
- [ ] Link verified and works
- [ ] "Last updated" note bumped
- [ ] No paid-only tools added
