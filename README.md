# Free AI Resources

A curated list of free AI model links and resources — alternatives to Claude and OpenAI.

## Models & APIs

- **Claude (Anthropic)** — claude.ai / api.anthropic.com
- **Gemini (Google)** — aistudio.google.com / Free tier via API
- **OpenRouter** — openrouter.ai — unified API for 100+ models, many with free tiers
- **Ollama** — ollama.ai — run LLMs locally for free
- **Groq** — groq.com — ultra-fast inference, generous free tier
- **Together AI** — together.ai — open model hosting
- **Hugging Face** — huggingface.co — open models & inference endpoints

## Tools

- **OpenClaw** — Local AI gateway for routing between Ollama and cloud APIs
- **AnythingLLM** — Self-hosted ChatGPT-like interface
- **LM Studio** — Desktop app for local LLMs
