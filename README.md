# Free AI Resources

A curated, verified list of **free AI models, APIs, and tools** — practical alternatives
to paid Claude/OpenAI plans, plus local, self-hosted options.

The full, sectioned list lives in **[`free-ai-resources.md`](./free-ai-resources.md)**.

## Features

- **100% free options** — models, aggregators, embeddings, image/video/audio generation,
  OCR, search, and code assistants.
- **Local & self-hosted** — run open-weight models on your own hardware (Ollama, LM Studio,
  AnythingLLM, …).
- **Verified links & limits** — rate limits and "last updated" notes are tracked per entry.
- **Curated by SolidAI** — practical picks for African businesses and communities, not an
  exhaustive directory.

## Contents

The full list is organized into:

| Section | What's inside |

| Open-weight models | Self-hostable checkpoints |

## Quick links (popular picks)

- [OpenRouter](https://openrouter.ai) — unified API for 100+ models, many with free tiers
- [Ollama](https://ollama.ai) — run LLMs locally for free
- [Groq](https://groq.com) — ultra-fast inference, generous free tier
- [Hugging Face](https://huggingface.co) — open models & inference endpoints
- [AnythingLLM](https://anythingllm.com) — self-hosted ChatGPT-like interface

See [`free-ai-resources.md`](./free-ai-resources.md) for the complete, maintained list.
